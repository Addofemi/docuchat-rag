# DocuChat RAG

An AI-powered Retrieval-Augmented Generation (RAG) chat application. Upload documents and interact with their contents through natural conversation backed by accurate source context.

## Features
- **Document Ingestion:** Parse and extract text from uploaded files.
- **Semantic Search:** Split text into chunks and retrieve relevant context.
- **Context-Aware Chat:** Answer user questions strictly grounded in document data.
